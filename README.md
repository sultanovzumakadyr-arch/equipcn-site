# Сайт Equipcn — equipcngroup.com

Сайт поставщика промышленного оборудования из Китая. Каталог собирается автоматически с магазина на Сату.

## Как это работает
1. `scraper/scrape.py` проходит по всем товарам на equipcngroup.com (Сату) и сохраняет описания, характеристики и фото (`data/scraped.json`, `site/img/`).
2. `scraper/build.py` собирает `site/index.html` из шаблона `template.html`.
   Группы, короткие названия и цены берутся из `data/curated.txt` — их можно править вручную.
   Новые товары с Сату попадают в подходящую группу автоматически.
3. GitHub Actions публикует сайт на GitHub Pages. Каталог обновляется сам каждое воскресенье.

## Обновить вручную
Вкладка **Actions → «Обновить каталог и опубликовать сайт» → Run workflow**.

## Править группу или название товара
Файл `data/curated.txt`, формат строки: `код|группа|название|цена|фото`.
Группы: metal, wood, build, agro, food, plast, power, pack, fish, glass, auto, mine, air, elec.
Цена: `~3000000` — «от 3 000 000 ₸», пусто — «цена по запросу».

## Скрыть товар с сайта
Добавьте его код в `data/hidden.txt` (по одному в строке).

## Добавить товар напрямую на сайт (без Сату)
Файл `data/extra.json` — список товаров. Фото кладутся в `site/img/` (имя `x<номер>_0.jpg`).
```json
[{"id": "x1001", "cat": "metal", "name": "Название", "price": "~2500000",
  "images": ["img/x1001_0.jpg", "img/x1001_1.jpg"],
  "desc": "Описание.\n\nАбзац 2.", "specs": [["Мощность", "3 кВт"], ["Вес", "1200 кг"]]}]
```
Коды таких товаров начинаются с `x`, чтобы не пересекаться с кодами Сату.
