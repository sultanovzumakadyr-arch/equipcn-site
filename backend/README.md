# Приём заявок Equipcn

Заявки с сайта сохраняются в Google Таблицу (она же — панель управления заявками), файлы клиентов — в папку на Google Диске.
Код: `Code.gs` (Google Apps Script, вставляется в таблицу). Установка — в комментарии в начале файла.

После развёртывания URL веб-приложения вписывается в `data/tracking.json` → `lead_endpoint`.
Пока `lead_endpoint` пустой, формы на сайте передают заявку через WhatsApp (запасной путь).

Листы таблицы:
- «Заявки» — все заявки: телефон, что нужно, товар, файл, источник, UTM, страница, устройство, статус, менеджер, комментарий.
- «Менеджеры» — список для выпадающего списка «Менеджер».
- «Отчёт» — заявки по источникам, кампаниям, статусам, неделям и страницам.
- «Сайт: реквизиты / проекты / отзывы / команда / видео заводов» — материалы для блока доверия на сайте.
  Показываются только строки с «да» в колонке «Показывать». Фото — ссылки Google Диска с доступом «все, у кого есть ссылка».

Уведомления: письмо владельцу таблицы о каждой заявке; Telegram — меню «Equipcn → Подключить Telegram».
