Описание

Станция для обслуживания автомобильных кондиционеров HONOW предназначена для проведения сервисных работ с системами автомобильного кондиционирования, использующими хладагент R134a. Оборудование помогает выполнять основные операции по обслуживанию системы кондиционирования в соответствии с возможностями выбранной модели.

Станция подходит для автосервисов, станций технического обслуживания и специализированных мастерских по ремонту автомобильных кондиционеров. Использование профессионального оборудования упрощает работу мастера и помогает организовать обслуживание систем кондиционирования на одном рабочем месте.
